# RiverSpendPanelControl (RSPC)

App separata e protetta per CEO e collaboratori autorizzati.

## Primo blocco
- shell mobile Android/iOS
- identità RSPC
- base pronta per autenticazione amministrativa
- futura dashboard e controllo dell'ecosistema RiverSpend

RSPC non deve diventare un accesso pubblico al marketplace: le autorizzazioni saranno gestite centralmente.
