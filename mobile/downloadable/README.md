# RiverSpend downloadable app shells

Seven installable Progressive Web App (PWA) starters: ISSA Sound, RiverCine, RiverSpaceSignals, RiverSpendShop, RiverSpendPark, RiverStreaming, RiverSSAI.

## Android
Host each folder over HTTPS, open its URL in Chrome, then choose Install app / Add to Home Screen. These are installable web apps, not signed APKs.

## iPhone/iPad
Host over HTTPS, open in Safari and use Share > Add to Home Screen. Native capabilities remain limited. Native iOS builds require macOS/Xcode, signing and testing.

Each folder contains HTML, manifest, service worker, and SVG icon. These are starter shells: real chat, payments, streaming catalogs, AI services, and advanced audio features are not yet integrated.


Additional starter folders added in this branch: `riverai/` (RiverSSAI shell) and `streaming/` (RiverStreaming shell).
