# RiverCloud RC-191–RC-194
These are deterministic utilities for caller-supplied data; they do not inspect live systems.

- RC-191 Evidence Consolidation: validates, bounds, and deduplicates evidence records.
- RC-192 Architecture Consistency: checks declared component IDs and invariant targets.
- RC-193 Interface Compatibility: flags explicitly declared breaking contracts.
- RC-194 Technical Debt Inventory: validates and ranks entries by severity.

Tests are authored in tests/rivercloud/rc-191-194.test.mjs; not executed in this commit.
No live telemetry, external scans, certification, or remediation is implied.
