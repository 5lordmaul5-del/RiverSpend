# RC257 — RiverSSAI Automatic Music Composer

## Goal
User prompt to structured musical concept and generated score. Target future live SSAI model orchestration.

## Prototype
Prompt, type, mood, tempo, bars, key and instrumentation selection; seeded scale-based melody demo; browser synth playback; JSON and simplified MIDI export.

## Limitation
This is a rule-based demonstration, not actual AI composition, multi-voice orchestration, lyrics, full song structure, realistic instrument sounds or production-ready MIDI. The RiverSSAI runtime is not connected.

## Planned actual AI pipeline
Prompt interpretation; creative brief and duration/structure; motif and harmony generation; verse/chorus/bridge for songs; orchestration and range/transposition checks; multi-track score; lyric generation when requested; playback and score rendering; iterative editing; MIDI/MusicXML/PDF/audio exports; quality validation and human review.
