# RC262 — RiverSSAI Digital Tuner

Experimental chromatic tuner prototype using browser audio input and simplified autocorrelation frequency estimation.

## Features
- Chromatic note name and estimated frequency display.
- Approximate cents deviation and visual needle.
- A4 reference calibration (400–480 Hz).
- Instrument presets and approximate string-frequency reference hints for standard guitar, bass, ukulele and violin.
- Audio input via microphone or compatible external interface.

## Limits
Prototype estimator; not calibrated/professional accuracy. Signal noise, harmonics, room acoustics, input setup and browser performance affect results. Preset hint is nearest-string heuristic and not a dedicated string recognition algorithm. HTTPS/browser permission requirements apply.
