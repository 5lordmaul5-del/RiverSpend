# RC232 — RiverStoryboard & Animatic Lab
Prototype for sequence/shot cards, optional image URLs, camera/framing and movement notes, duration, reorder/delete, timed slideshow animatic and JSON export.

## Limitations
The preview is a timed still-image slideshow, not video editing or generated storyboard art. No audio, scene-level screenplay linkage, collaborative review, autosave or rendering. No tests run. Draft only, no merge/deploy.
