# RC256 — River Music Engine & Live Score Core

## Prototype
Interactive pitch-grid score editor with click-to-toggle note events, tempo, basic browser-tone playback, JSON, MIDI and MusicXML exports.

## Scope and limitations
One monophonic melody line, small pitch set, simplified MIDI/MusicXML output and synthesized browser playback. This is not yet a multitrack orchestration engine, real-time AI composition, instrument-specific notation, full MusicXML correctness, or production audio synthesis. The prototype is a first step toward score editing and interchange.

## Next architecture
Multi-voice score model, rhythmic values and rests, staff rendering, transposing instruments, playback via sample/synth engine, score editing operations, RiverSSAI composition API, validation and exports.
