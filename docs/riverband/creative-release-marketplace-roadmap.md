# RiverSpend creator-to-Shop roadmap

## Target
Finish content in VirtualSoundStudio / ISSA, prepare rights and metadata documentation, then optionally offer a physical CD or permitted digital product in RiverSpendShop.

## Work packages
- A: studio export checklist and metadata editor.
- B: RiverSSAI-assisted metadata and rights checklist (suggestions, not legal certification).
- C: RiverCloud versioning and private evidence/receipt storage with recovery design.
- D: official-service handoff links and instructions (SIAE, Soundreef, distributors); no unsupported API automation.
- E: distribution adapter registry for manual links or approved APIs, confirmations and withdrawal.
- F: creator catalog in RiverSpendShop: CDs, downloads, previews, rights declaration, fulfilment and support.
- G: payments, VAT/tax, consumer disclosures, privacy and security review.

## Release checklist
- [ ] Composition and recording rights confirmed
- [ ] Contributor agreements and credits reviewed
- [ ] Samples, covers and adaptations cleared
- [ ] Artwork/video rights confirmed
- [ ] Metadata validated
- [ ] Identifiers only entered if assigned
- [ ] Submission receipt attached
- [ ] Shop terms and territories checked
- [ ] Digital/physical fulfilment and refunds tested
- [ ] Payment/compliance review complete
