# Creator Export Manifest

This module structures a simple export inventory for a creator's audio/video release and provides an advisory gate for Shop handoff. It does not generate the media files, compute cryptographic checksums, verify ownership, or certify compliance.

Assets should eventually include audio masters, preview clips, cover artwork, video variants, optional stems, lyric sheets and delivery formats. Checksums are optional fields and must only be populated after real computation. Shop handoff requires explicit rights confirmation, defined territories and reviewed delivery terms; the current helper is a planning gate, not a transaction or legal determination.
