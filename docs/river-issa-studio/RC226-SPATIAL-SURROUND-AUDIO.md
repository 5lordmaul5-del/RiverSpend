# RC226 — River ISSA Spatial Audio / Surround Lab

Prototype to explore stereo panning, gain and width control, and selectable conceptual routing layouts (2.0, quad, 5.1, 7.1, binaural). The current prototype plays through browser stereo output and does not implement true multi-channel rendering, HRTF, Dolby codecs, Atmos or licensed Dolby processing.

## Roadmap
- Stereo pan and gain
- Width processing research and implementation
- HRTF/binaural positioning
- True multichannel routing and channel export
- Game-engine audio bus integration
- Licensed standards/branding validation before using Dolby trademark or certified workflows

This is not Dolby-certified and is not a Dolby product. Surround presets are layout simulations only.
