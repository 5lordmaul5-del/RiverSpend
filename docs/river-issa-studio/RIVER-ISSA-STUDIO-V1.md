# River ISSA Studio — V1

Goal: establish the creative studio foundation for RiverSpend's game and media ecosystem.

## Scope
- Browser-local audio and video capture.
- Imported audio playback and basic Web Audio processing.
- Gain, selectable filter and delay.
- RiverBox asset metadata generator.
- Plugin Bay roadmap and capability boundaries.

## Roadmap
1. Audio asset pipeline: normalized WAV/OGG exports, metadata, pack manifest and loop markers.
2. Multi-track editor: timeline, waveform, non-destructive editing, markers and undo.
3. Plugin API with sandbox, versioning, CPU/memory/output limits.
4. EQ, compressor/limiter, gate, reverb, spatial/binaural, pitch/time.
5. Video editor, sync, proxy, color and export.
6. RiverBox runtime: loader, music/SFX buses, adaptive/3D audio, triggers, ducking.
7. Native desktop engine and future VST/AU bridging.

Media capture requires permission. This demo does not upload recordings, persist media server-side or access media in background.
