# Mixer effect bypass controls

Adds per-track effect enable/disable buttons for EQ, Delay, Compressor and Reverb.

- EQ bypass sets the three EQ node gains to neutral (0 dB).
- Delay bypass disables the wet path and feedback.
- Compressor bypass sets its ratio to neutral (1:1).
- Reverb bypass disables the wet gain.
- Controls retain their settings when toggled off and back on.

Browser-local prototype; runtime validation has not yet been performed.
