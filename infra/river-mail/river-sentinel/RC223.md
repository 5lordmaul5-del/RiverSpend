# RC223 — River Sentinel Intelligence Engine

## Purpose
Correlate privacy-preserving account-security events into explainable risk levels and recommended user actions.

## Prototype features
- event normalization validation (prototype only)
- pseudonymous user-key grouping, never message-body input
- signal scoring with explicit rule weights
- three correlation patterns: login anomaly cluster, account-persistence cluster (forwarding + OAuth), phishing cluster
- four risk levels: GREEN / YELLOW / ORANGE / RED
- actionable recommendations, not automatic account punishment or content access

## Deployment prerequisites
Authentication, tenant isolation, event schema validation, rate limits, secure storage, alert delivery, access audit, retention controls, independent review and a privacy/legal assessment. The prototype uses a simple pseudonymous key and is not a production identity or authorization system.
