# RC217 RiverMail Integrated Core\n\nRiverMail prototype for the RiverSpend ecosystem.\n\n- SQLite mailbox core, search, read state.\n- Integration notification bridge for RiverSpendShop, RiverSpaceSignals, RiverSSAI.\n- Event queue and processed status.\n- Tests authored (not run here).\n\n## Demo only\nNo SMTP/IMAP/POP, real accounts, DNS, remote deployment, authentication, attachments, spam filtering, encryption at rest or production email delivery.\n\n## Production roadmap\n1. Account identity, MFA/passkeys, recovery and anti-abuse.\n2. SMTP/MX, SPF/DKIM/DMARC, TLS, reputation, bounce management.\n3. API and IMAP-style synchronization, folders, attachments, quota and retention.\n4. RiverMail Shield spam/phishing/malware protection.\n5. Consent-controlled integrations and notification preferences.\n6. GDPR workflow, encryption, key management, backups, audit and incident response.\n7. Security/load review before launch.\n\nEmail privacy: app integrations should send minimal, user-configurable notifications, not access mailbox content without explicit consent.
