# PowerTron
PowerTron coordinates Fulcron tasks.
- Registry: 101 disabled role definitions.
- Coordinator: deterministic routing suggestions.
- Queue: durable local task storage and audit trail (single-process).
- Dispatcher: advisory assignment preview; execution disabled.
- Explicit approval is required before future execution.

Not yet production service: authentication, access control, concurrency-safe transactional storage, verified backup/restore and worker isolation remain outstanding.
