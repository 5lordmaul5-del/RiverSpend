# RC-171 — RSEngineer review toolkit

Deterministic text-pattern triage helpers for supplied code/text snippets. Checks selected markers for secret-like content, dangerous command strings, unsafe execution APIs and network operation markers.

## Use
Import `review_text` and pass text. `summarize` returns severity counts and a review-required flag.

## Limitations and safety
This is not a static analyzer, sandbox, secret detector, or security guarantee. It can miss risks and produce false positives. It inspects supplied text only, never reads files, runs code, or contacts the network. Human review remains mandatory. Tests are authored, not verified in this session.
