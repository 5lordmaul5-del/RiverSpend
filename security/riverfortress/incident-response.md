# RiverFortress incident response

1. Declare incident; record timestamp, symptoms, affected services and reporter.
2. Contain: revoke compromised credentials and isolate affected systems where appropriate.
3. Preserve evidence: secure logs, snapshots and timestamps; document actions.
4. Assess scope: systems, accounts, data, dependencies and backup integrity.
5. Recover: rebuild from trusted images, rotate secrets and restore verified clean data.
6. Verify: security controls, data consistency, monitoring and functionality.
7. Communicate with providers, affected users, counsel and authorities where required.
8. Post-incident: timeline, root cause, actions, owners and verification.

Never erase evidence, conceal data, bypass lawful restrictions, or promote an unverified standby.
Keep an offline list of contacts and account-recovery instructions; never put passwords or recovery codes in this document.
