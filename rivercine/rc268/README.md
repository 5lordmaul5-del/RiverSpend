# RC268 — RiverCine Virtual Pedalboard & Routing

Browser Web Audio prototype with interactive serial pedal order and toggles:
- Boost
- Overdrive and Fuzz (waveshaper simulations)
- Chorus / Phaser (simple filter-based approximations)
- Delay with feedback
- Reverb (generated impulse response)
- Simple amp saturation and low-pass cabinet approximation
- Clean, Rock and Ambient presets
- Pedal order controls (move up/down)
- Microphone input (permission-gated) and test tone

Open on HTTPS or localhost for microphone support. Lower output before test tones.

**Limitations:** approximations, not hardware/device models; no actual cabinet convolution IR, multitrack recording, MIDI, plugin hosting, or production audio routing. Test on browser/device before real use.
