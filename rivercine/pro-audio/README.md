# RC264 — RiverCine Pro Audio Equipment & Brand Catalogue

Adds focused catalogue sections for acoustic/electronic drums and genre kits (including heavy metal, rock, double kick and hybrid kits), drum mics, professional vocal and studio mics, studio monitors, guitar/bass amplifier types, and guitar/electro-acoustic/semi-acoustic families. Manufacturer reference lists include B&W, Yamaha, Takamine, Rickenbacker, Marshall, Ampeg and other major manufacturers.

- **247** entries
- Search/filter HTML browser
- JSON data catalogue

Brand entries are references, not endorsements, partnerships, model-specific presets or confirmed compatibility. This draft does not yet implement hardware drivers, amp/effect simulations or real-world validation.
