# RC267 — RiverCine FX Suite

Browser-based Web Audio prototype for a configurable effect chain.

- Three-band EQ (low shelf, mid peaking, high shelf)
- Basic noise gate threshold
- Waveshaper drive
- Delay with feedback
- Convolution reverb with wet control
- Lightweight modulation/chorus simulation
- Presets: Clean, Rock Drive, Ambient, Vocal
- Microphone and test-tone input (permission required for microphone)

## Run
Open `index.html` on localhost or HTTPS. Microphone access requires browser permission.

## Limitations
Prototype only: no multitrack recording/export, MIDI, production-grade gate, sophisticated chorus modulation, advanced routing, plugin hosting or device control. Test tone may be loud; lower levels first.
