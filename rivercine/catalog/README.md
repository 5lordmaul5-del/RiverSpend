# RC263 — RiverSSAI / RiverCine Universal Instrument & Effects Catalog

This branch adds a searchable catalogue UI and JSON taxonomy of instruments, studio hardware, vocal effects, guitar/bass pedal effects, modulation, pitch, distortion, echo, delay, reverb, filters, creative sound design and routing.

## Contents
- `rivercine/catalog/catalog.json`: structured entries with IDs, category and metadata.
- `rivercine/catalog/index.html`: simple catalogue browser.
- `rivercine/catalog/catalog.js`: search/filter UI logic.

The catalogue includes **174 instrument/hardware entries** and **151 effects entries** (325 total). This is a taxonomy/catalogue scaffold, not a claim that each effect or device is already implemented or tested. Processing, MIDI/audio compatibility and hardware support remain future integration and verification work.
